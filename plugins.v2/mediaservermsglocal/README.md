# 媒体服务器通知本地版

版本：1.0.31。基于媒体服务器通知魔改版，消息图片通过 ImageLocalCache 本地缓存代理提供。

## 配置

1. 安装并启用 ImageLocalCache，填写外部消息客户端可访问的域名。
2. 在本插件中选择媒体服务器，启用“新入库”通知。
3. 需要聚合时开启 TV 聚合并设置等待秒数，例如 60 秒。每收到一条同剧通知都会重新计算等待时间。
4. 如需点击通知跳转播放，启用播放链接选项。
5. 避免同时开启本插件与其他相同用途通知插件，否则可能收到重复通知。

## 解析与计数

支持标准化季集字段、Emby Item 季集字段、合并文件的 IndexNumberEnd，以及 Description 中的完整季集列表。
例如 `S01 E25, E29` 显示为 `S01E25, S01E29`，`S01 E26-E27` 显示为 `S01E26-E27`，均计为 2 集。
特别篇保留 S00，重复季集去重，不同服务器分别聚合。

聚合、非聚合和元数据降级路径都使用图片缓存插件的外部域名；已代理的图片不会被重复嵌套。
图标使用 MP 内置 mediaplay.png；保留匿名 /icon 接口以兼容旧引用。

## 验证范围

包含独立回归测试；已通过 Emby 原生测试通知、历史单集/多集入库报文回放和企业微信手机接收验证。
报文回放不等同于新增真实媒体的完整扫描测试。普通通知还受 MP 全局允许发送时段约束，聚合等待时间是独立设置。
